## Matrix conclusion

**Recommendation.** Use Direct `AgentHarness` as the sole G002 primary path,
with an adapter that pins the source commit, performs orchestration only after
`await prompt()` returns, owns the external verifier and run journal, passes an
explicit `NodeExecutionEnv`, and records/limits retry and compaction behavior.

**Recommendation.** The previous `Pi SDK Runner + Inline Extension` candidate
is **superseded as the V0 experimental runtime basis**, not deleted from the
roadmap. Retain it as a bounded compatibility check for the later real Pi
usage path, because it has the mature `agent_settled`, automatic retry and
auto-compaction semantics that Direct does not yet implement.

**Recommendation.** Keep RPC/process as a fallback only if G002 demonstrates a
specific in-process isolation or lifecycle failure. Do not reject Pi on static
evidence: no current Go/No-Go criterion is a hard blocker for a deterministic,
single-process, non-crash-recovery V0 spike.
