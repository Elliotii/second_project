re-audit. V1-C is not closed. The project continues toward the original

## Execution rules

The future fresh no-source-edit Session must:

1. start from the exact Main-owned clean launch baseline;
2. use the additive R2 Manifest and disjoint Pilot root;
3. use the accepted opaque loader semantics without inspecting the Credential;
4. execute exactly one next cell per process and inspect it before continuing;
5. keep retry, fallback and automatic replacement disabled;
6. retain at most 24 initial cells, 8 child Attempts and USD 1.90 for the
   restarted Pilot;
7. stop on unknown usage/cost, evidence conflict, invalid thresholds,
   nonterminal prior cells, secret boundary failure or another material
   Contract Pause Condition;
8. correct a strictly pre-product, zero-side-effect command/path typo rather
   than misclassify it as a Pilot failure.
